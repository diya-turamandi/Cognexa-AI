
# Cognexa AI

### Your Knowledge. Connected. Intelligent.

Cognexa AI is an AI-powered personal knowledge
management platform that transforms documents
into an intelligent, searchable knowledge base.

## Core Features

- Document upload and management
- AI-powered document understanding
- Semantic search
- RAG-based question answering
- Conversational document assistant
- Knowledge retrieval across documents

## Technology Stack

- React.js
- Tailwind CSS
- Python
- FastAPI
- PostgreSQL
- Qdrant
- LangChain
- Docker

## Project Status

Currently building the foundational architecture.
